# Archived code

These files were moved out of the project root because they are superseded by the current pipeline or were one-off audits and exploratory analyses. They are retained so old results remain reproducible.

- `legacy_vecm_km/`: pre-VECM3 and pre-KM-V8 notebooks/scripts.
- `legacy_aft/`: pre-AFT-V8 fits, reconstructions, plots, and summary tables, plus the stopped bivariate experiment.
- `legacy_survival/`: older survival-analysis workflows and data-pull modules.
- `validation_experiments/`: completed audits, benchmarks, robustness runs, and random-grid experiments.
- `old_analysis/`: older volume, open-interest, VIF, and exploratory plotting utilities.
- `maintenance/`: one-off file-organization utilities.

The active pipeline is documented in `README.md` at the project root. Older
inventories, workflow notes, timing notes, and the former paper manifest are
retained under `maintenance/`. Files can be restored with `Move-Item` if an
archived result needs to be reproduced.
